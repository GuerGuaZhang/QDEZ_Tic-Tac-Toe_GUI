# 《二中棋》逆向工程与 GUI 复刻

> 基于对原版 `二中棋.exe` 的逆向工程，使用 Python + Tkinter 全新实现的图形界面版本。

## ✨ 特性

- **完整功能复刻**：忠实还原原版所有功能，包括随机事件系统、人机AI、神秘事件彩蛋
- **三种游戏模式**：单人（人机先手/后手）、双人对战
- **随机事件系统**：12种事件类型，包括消除格子/行/列/对角线、帮你下一手、反转局势、神秘事件
- **5层AI策略**：赢→挡→中心→线扩展→固定顺序兜底，完全对齐原版逻辑
- **神秘事件彩蛋**：累计5次触发Windows崩溃整蛊效果
- **双输入支持**：同时支持鼠标点击和键盘操作（wsad+空格/方向键+Enter）

## 🚀 快速开始

### 前置条件

- Python 3.6+
- Tkinter（Python 标准库，通常已包含）

### 安装 / 使用

1. 克隆仓库：
   ```bash
   git clone https://github.com/GuerGuaZhang/二中棋.git
   cd 二中棋
   ```

2. 运行游戏：
   ```bash
   python src/二中棋_GUI.py
   ```

3. 游戏操作：
   - **主菜单**：点击按钮或使用键盘快捷键（S/H/P/E）
   - **游戏设置**：调节速度、切换键盘偏好
   - **游戏对局**：鼠标点击落子，或使用键盘移动光标+空格/Enter落子

## ⚙️ 游戏说明

### 基本规则
- 3×3 三子棋，○/× 对弈
- 每人轮流落子，三子连线即获胜
- 每手落子后触发随机事件，增加游戏不确定性

### 随机事件类型
- 消除格子/行/列/对角线（概率约 33% + 8%×4）
- 帮你下一手（8%）
- 反转局势（8%，50%概率生效）
- 神秘事件（17%）：累计5次触发彩蛋

### 键盘操作
- **wsad组**：W/A/S/D移动方向，空格落子
- **方向键组**：↑/←/↓/→移动方向，Enter落子
- 双人模式两组键都可用，单人模式使用设置中的偏好组

## ❓ 常见问题

**Q: 游戏无法运行？**
A: 确保已安装Python 3.6+，Tkinter通常随Python一起安装。如缺少Tkinter，请安装python-tk包。

**Q: 如何切换游戏模式？**
A: 在主菜单点击"开始游戏"，然后选择A/B/C模式。

**Q: 神秘事件彩蛋是什么？**
A: 累计触发5次神秘事件后，会显示Windows崩溃整蛊效果，然后重置游戏。
